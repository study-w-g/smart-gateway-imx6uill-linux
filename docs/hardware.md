## 硬件确认清单

- [ ] 确认原理图和接口引脚定义。
- [ ] 确认 GPIO 编号和有效电平。
- [ ] 使用 `i2cdetect` 确认 I2C 总线编号和 SHT30 地址。
- [ ] 确认 UART 电平、波特率和接线。
- [ ] 对不确定的时序保存逻辑分析仪记录。
- [ ] 所有参数确认后再更新设备树。
