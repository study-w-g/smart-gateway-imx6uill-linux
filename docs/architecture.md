# 系统架构

```text
传感器/GPIO/UART
      |
设备树 + Linux 驱动
      |
/dev、sysfs、poll/event
      |
网关管理服务（用户态）
      +--> Qt 本地监控
      +--> MQTT 遥测与命令通道
      +--> LED / LX-16A 控制
```

## 各层职责

| 层次 | 职责 |
|---|---|
| 设备树 | 描述总线、GPIO、地址、引脚复用和硬件关系 |
| 内核驱动 | 将 Linux 接口转换为总线事务、中断处理和设备状态管理 |
| 用户态服务 | 汇总传感器数据、执行阈值判断、处理事件并恢复故障 |
| Qt 界面 | 显示数据并发出本地控制命令 |
| MQTT 客户端 | 上传遥测数据并接收远程命令 |

## 设计原则

1. 硬件访问位于用户态服务以下的层次。
2. 界面不直接访问寄存器或 GPIO。
3. 驱动接口返回明确的错误码。
4. 使用阻塞读取和 `poll()` 实现事件驱动数据流，避免忙等待。
5. 所有外部控制命令在执行前都必须校验。
